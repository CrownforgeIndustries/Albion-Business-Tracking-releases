
# [EN] Albion Business Tracking

Desktop application for managing the finances of your businesses in Albion Online.

## Download

In the Releases section (on the right), you'll find the latest version:
- Installer (...setup.exe): install it and you're ready to go. It will automatically notify you when a new version is available.
- Portable version (...portable.zip): extract the file and run the application without installing anything. You can carry it on a USB drive.


## Web Version
If you prefer not to install anything, you can use the browser version here:

https://albion-business-tracking-web.crownforgeindustries.workers.dev/

# [ES] Albion Business Tracking

App de escritorio para llevar la economía de tus negocios en Albion Online.

## Descargar

En la sección **Releases** (a la derecha) tienes la última versión:

- **Instalador** (`...setup.exe`): instálalo y listo. Avisa solo cuando sale una versión nueva.
- **Portable** (`...portable.zip`): descomprime y ejecuta, sin instalar. Se puede llevar en un USB.

## Versión web

Si prefieres no instalar nada, tienes la versión de navegador aquí: https://albion-business-tracking-web.crownforgeindustries.workers.dev/
